The capacity calculator

A Fabric App barely consumes any capacity units. That isn't the problem. The problem is that hosting one means you can no longer pause the capacity — so you buy an always-on SKU for a workload that uses a fraction of it. This works out what that actually costs.

Read this before you use it. It is not an official Microsoft tool, it is not tested, and the CU coefficients are my own rough estimates rather than published figures. Every one of them is editable in the tool. Do not use it to quote a customer, size a purchase, or make a budget decision.

Why these notes read the way they do

They are working notes, written in the first person, with the mistakes left in. That is deliberate. Almost every useful line here exists because I got something wrong first — and the wrong turn is usually more instructive than the fix.

The single lesson I would keep if I could keep only one:

A typecheck, 54 unit tests, 57 end-to-end tests and a lint pass were all green while the app rendered an entire valley wrong. Anything that only fails as a fetched filename or a rendered pixel survives the whole verification chain. After every deploy, actually open the thing and look at it.
